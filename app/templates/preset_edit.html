Shown on your status page (e.g. requests.example.com) only if the server goes offline while this notice is active. When you activate with "Also set this preset's message" ticked, it's sent to Cloudflare before anything goes down. Leave both empty to use the default "unexpected outage" message from Settings.

How long does it stay?
If you set an auto-remove time when activating, the message expires one hour after that time. Otherwise it expires after the number of hours set in Settings → Cloudflare (default 24). It's also cleared when you remove the notice. That way an old "electrical work" message can never show up weeks later during an unrelated outage.
